# Stream Vibe

A responsive frontend project for a streaming service, built with React, SCSS, and JavaScript.

## About

Stream Vibe is a practice frontend project based on a [Figma design](https://www.figma.com/design/YzTDRV7OaSoeCUBNYaoCZV).

The project focuses on reusable UI components, a clear page and section structure, and responsive layouts.

## Tech Stack

- React
- JavaScript (ES modules)
- SCSS (Sass)
- Minista
- Vite
- Swiper
- IMask
- npm

## Project Structure

- `src/pages/` — page entry points and dynamic movie/show pages
- `src/components/` — reusable interface components
- `src/sections/` — page sections
- `src/layouts/` — shared page layout components
- `src/styles/` — global styles, variables, and SCSS helpers
- `src/assets/` — images and other source assets
- `src/main.js` — client-side JavaScript entry point
- `public/` — static files served as-is

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the production site:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Available Scripts

- `npm run dev` — start the development server
- `npm run build` — build the site into `dist/`
- `npm run preview` — preview the production build
